# UI

Part of [Multi-Profile & Per-Game Tracking](./README.md). Depends on
[03-scope-model.md](./03-scope-model.md) for the scope concept.

## Profile switcher

- **Entry point:** a profile chip in the app bar showing the active profile's name and its caught
  count for the active scope (e.g. "Ash · 42/151").
- **Tap:** a bottom sheet listing profiles, with the active one checked. Each row shows its own
  caught count. A "New profile" action at the bottom.
- **Long press or menu:** rename, reset, or delete. Delete is blocked for the last profile
  ([O2](./00-decisions.md#still-open)).
- Switching is immediate, with no restart.

## Scope selector

- A horizontal chip row in the filter section (`lib/widgets/filter_section.dart`), next to the
  existing filters, so it stays visible while browsing.
- Options, in order: **National (all games)**, **National (manual)**, then one chip per game in
  version-group order.
- Each chip shows its own progress count.
- Selecting a scope updates the list, the caught filter, and the counts. It persists per profile.
- The **National (all games)** chip is read-only. Its tiles show a small "caught in N games"
  badge instead of a checkbox (D5).

## Pokémon list

- Caught indicators follow the active scope.
- Pokémon outside a game's regional dex are hidden in that game's scope, as described in
  [03-scope-model.md](./03-scope-model.md).
- Caught filter (`FilterModal`) works against the active scope.

## Pokémon details

- The existing caught toggle writes to the active scope.
- A new "Caught in" section lists every game the profile has marked this Pokémon caught in, with
  each game's name and a link to switch scope to it.
- In derived National, the toggle is replaced by the "Caught in" section plus a hint to choose a
  scope (D5).

## Catch screen

- Catch-probability calculations are unchanged.
- The caught state it reads comes from the active scope.

## Game picker

- A dedicated list of games (version groups), showing titles and generations. Used by the scope
  selector and by any "add game" action.
- Data already exists through `PokemonService.getVersionGroup`. The picker is a new widget.

## Hamburger menu

- "Profiles" entry (switch, add) and the existing export/import entries, labelled with the active
  profile name.

## Acceptance

- Switching profile or scope updates every visible caught indicator without a restart.
- In derived National, no tile accepts a direct tap-to-toggle.
- Each game chip's progress count matches the number of visible caught rows for that game.
